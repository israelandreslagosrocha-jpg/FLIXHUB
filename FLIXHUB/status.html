⚙️ Compilar SASS a CSS

Para editar los estilos, necesitas compilar SASS a CSS. Elige una opción:

1
Opción A: Instala SASS globalmente
npm install -g sass
sass layout/main.scss styles.css
2
Opción B: Compilador online
Usa: jsoncrack.com
3
Opción C: VS Code Live Sass Compiler
Instala extensión y haz click en "Watch Sass"
