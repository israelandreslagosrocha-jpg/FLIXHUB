2️⃣ EFECTOS JAVASCRIPT INTERACTIVOS
──────────────────────────────────────────────────────────────────────────────

EFECTO PARALLAX 3D EN TARJETAS:
  • Cuando pasas el cursor sobre una tarjeta, se crea un efecto 3D
  • La tarjeta se inclina siguiendo la posición del cursor
  • Efecto perspective(1000px) para profundidad
  • Rotación suave en los ejes X e Y
  • Al salir el cursor, vuelve a su posición normal

EFECTO DE BRILLO (SHINE):
  • Gradiente radial que sigue el cursor
  • Animación fluida al pasar sobre la tarjeta
  • Crea efecto de luz reflejada

EFECTO DE ELEVACIÓN:
  • La tarjeta sube levemente al pasar el cursor
  • Transform: translateY(-8px)
  • Sombra aumenta para dar sensación de profundidad

EFECTO RIPPLE EN BOTONES:
  • Al hacer clic en un botón, se crea una onda (ripple)
  • La onda se expande desde el punto donde hiciste clic
  • Color blanco semi-transparente
  • Duración de 0.6 segundos


3️⃣ ESTILOS CSS NUEVOS
──────────────────────────────────────────────────────────────────────────────

ANIMACIONES:
  @keyframes shine       → Efecto de brillo en movimiento
  @keyframes ripple-animation → Onda en expansión

PROPIEDADES:
  • transform-style: preserve-3d → Habilita transformaciones 3D
  • perspective(1000px) → Crea efecto de profundidad
  • animation → Para efectos suaves

EFECTOS DE HOVER:
  • Aumento de sombra
  • Movimiento vertical
  • Cambios de opacidad
  • Transiciones suaves (0.3s)


4️⃣ CÓMO FUNCIONAN LOS EFECTOS
──────────────────────────────────────────────────────────────────────────────

CUANDO PASAS EL CURSOR SOBRE UNA TARJETA:
  1. Se detecta la posición exacta del cursor
  2. Se calcula la distancia desde el centro de la tarjeta
  3. Se aplica rotación 3D basada en esta distancia
  4. Se crea efecto de brillo que sigue al cursor
  5. La tarjeta se eleva suavemente
  6. Todo sucede en tiempo real y suavemente

CUANDO HACES CLIC EN UN BOTÓN:
  1. Se detecta la posición exacta del clic
  2. Se crea un elemento circular (ripple)
  3. El ripple se posiciona en el punto del clic
  4. Se expande y desaparece gradualmente
  5. Dura 0.6 segundos


5️⃣ CÓDIGO JAVASCRIPT AGREGADO
──────────────────────────────────────────────────────────────────────────────

// Efectos 3D en cards
cards.forEach(card => {
    card.addEventListener('mousemove', (e) => {
        // Calcula rotación basada en posición del cursor
        const rotateX = (y - rect.height / 2) / 10;
        const rotateY = (x - rect.width / 2) / 10;
        
        // Aplica transformación 3D
        card.style.transform = `perspective(1000px) rotateX(${rotateX}deg) rotateY(${rotateY}deg) translateZ(10px)`;
    });
    
    card.addEventListener('mouseleave', () => {
        // Restaura posición normal
        card.style.transform = 'perspective(1000px) rotateX(0) rotateY(0) translateZ(0)';
    });
});

// Efecto ripple en botones
btn.addEventListener('click', (e) => {
    // Crea elemento ripple
    const ripple = document.createElement('span');
    ripple.style.animation = 'ripple-animation 0.6s ease-out';
    
    btn.appendChild(ripple);
    
    // Lo elimina después de la animación
    setTimeout(() => ripple.remove(), 600);
});
