🏗️ ARQUITECTURA DEL PROYECTO:
───────────────────────────────────────────────────────────────────────────────

ORGANIZACIÓN SASS (7-1 Pattern):

  abstracts/          → Variables y mixins (reutilizables)
  base/               → Reset y tipografías (globales)
  components/         → Botones y tarjetas (modular)
  layout/             → Header, footer y main (estructura)

🚀 CÓMO USAR:
───────────────────────────────────────────────────────────────────────────────

INMEDIATO (0 instalaciones):
  1. Abre: index.html en cualquier navegador
  2. ¡La página está lista para usar!

CON PERSONALIZACIÓN (si instalas SASS):
  1. Instala Node.js (https://nodejs.org/)
  2. npm install -g sass
  3. Edita archivos .scss
  4. sass layout/main.scss styles.css
  5. Recarga la página (F5)


⚙️ COMPILACIÓN SASS:
───────────────────────────────────────────────────────────────────────────────

Comando básico:
  sass layout/main.scss styles.css

Modo watch (automático):
  sass --watch . --output .

Para producción (minificado):
  sass layout/main.scss styles.min.css --style=compressed

Scripts npm (si instalaste):
  npm run sass
  npm run sass:watch
  npm run sass:prod
