OPCIÓN B: COMPILAR SASS PERSONALIZÁNDOLO
  1. Instala SASS: npm install -g sass
  2. Edita cualquier archivo .scss
  3. Compila: sass layout/main.scss styles.css
  4. Abre index.html en navegador
  5. Recarga (F5) para ver cambios

OPCIÓN C: COMPILACIÓN AUTOMÁTICA
  1. Instala SASS: npm install -g sass
  2. Ejecuta: sass --watch . --output .
  3. El CSS se regenerará automáticamente al guardar


⌨️ COMANDOS ÚTILES:
═══════════════════════════════════════════════════════════════════════════

Compilar SCSS a CSS:
  $ sass layout/main.scss styles.css

Modo watch (compilación automática):
  $ sass --watch . --output .

Compilar minificado (producción):
  $ sass layout/main.scss styles.min.css --style=compressed

Usando npm (si instalaste dependencias):
  $ npm run sass
  $ npm run sass:watch
  $ npm run sass:prod

💡 MODIFICACIONES RÁPIDAS POPULARES:
═══════════════════════════════════════════════════════════════════════════

Cambiar color rojo Netflix → otro color:
  1. Abre: abstracts/variables.scss
  2. Encuentra: $color-primary: #e50914;
  3. Cambia: #e50914 por tu color (ej: #0ea5e9 para azul)
  4. Compila: sass layout/main.scss styles.css
  5. Recarga: Abre index.html y presiona F5

Cambiar fondo oscuro:
  1. Abre: abstracts/variables.scss
  2. Encuentra: $color-bg: #141414;
  3. Cambia: #141414 por tu color
  4. Compila y recarga

Cambiar nombre del sitio:
  1. Abre: index.html
  2. Busca: <a href="#" class="nav__logo">FlixHub</a>
  3. Cambia: FlixHub por tu nombre
  4. Guarda y recarga

Añadir película:
  1. Abre: index.html
  2. Copia una tarjeta .card
  3. Modifica imagen, título, descripción
  4. Guarda y recarga
