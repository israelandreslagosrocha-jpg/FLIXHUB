🎬 FLIXHUB - PLATAFORMA DE PELÍCULAS CON SASS
===============================================

📂 ESTRUCTURA DEL PROYECTO:

scss/
│
├── 📄 index.html                 ← PÁGINA PRINCIPAL (abre en navegador)
├── 📄 styles.css                 ← CSS COMPILADO (generado automáticamente)
├── 📄 package.json               ← Configuración para compilar SASS
├── 📄 README.md                  ← Documentación completa
├── 📄 GUIA_RAPIDA.md            ← Guía de inicio rápido ⭐
├── 📄 COMPILACION.scss           ← Cómo compilar SASS
│
├── 📁 abstracts/
│   ├── variables.scss            ← Colores, fuentes, espacios
│   └── mixins.scss               ← Funciones reutilizables
│
├── 📁 base/
│   ├── reset.scss                ← Reset CSS global
│   └── typography.scss           ← Tipografías
│
├── 📁 components/
│   ├── buttons.scss              ← Estilos de botones
│   └── cards.scss                ← Estilos de tarjetas
│
└── 📁 layout/
    ├── header.scss               ← Encabezado y navegación
    ├── footer.scss               ← Pie de página
    └── main.scss                 ← Archivo principal (importa todo)


🎯 INICIO RÁPIDO:
================

1. Abre index.html en tu navegador
   → La página ya está funcional

2. Si quieres editar estilos:
   → Edita cualquier archivo .scss
   → Compila con: sass layout/main.scss styles.css
   → Recarga la página (F5)

📝 CÓMO EDITAR:
===============

Cambiar colores:
  ↓ Edita abstracts/variables.scss
  ↓ Compila: sass layout/main.scss styles.css

Cambiar botones:
  ↓ Edita components/buttons.scss
  ↓ Compila el archivo

Cambiar tarjetas:
  ↓ Edita components/cards.scss
  ↓ Compila el archivo

Añadir películas:
  ↓ Edita index.html
  ↓ Duplica un bloque .card


⚙️ COMPILAR SASS:
=================

Opción 1: Node.js (Recomendado)
  $ npm install -g sass
  $ sass layout/main.scss styles.css
  $ sass --watch . --output .    (modo watch)

Opción 2: Online
  https://jsoncrack.com/editor

Opción 3: Visual Studio Code
  → Instala extensión "Live Sass Compiler"
  → Click en "Watch Sass"
